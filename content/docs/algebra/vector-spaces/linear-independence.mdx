A set is linearly independent when the only combination giving $0$ is the trivial one. This page tests independence by row reduction and shows that it is exactly the condition for coefficients to be unique.

## Independence removes redundancy

<Recall of="span" />

<Definition slug="linear-independence" of="linear-combination,span">

### Linear independence

<Statement>

Let $S$ be a subset of a vector space over $F$. The set $S$ is *linearly
independent* if every finite list of distinct vectors
$u_1,\ldots,u_n\in S$ has the property that, for scalars
$\lambda_1,\ldots,\lambda_n\in F$,
$$
\lambda_1u_1+\cdots+\lambda_nu_n=0
$$
implies
$$
\lambda_1=\cdots=\lambda_n=0.
$$

</Statement>

An equation of this form is a relation among the chosen vectors. An
independent set is one in which the zero vector has no non-trivial finite
representation. An independent set therefore cannot contain the zero vector
itself.

</Definition>

<Definition slug="linear-dependence" of="linear-independence">

### Linear dependence

<Statement>

A set $S$ is *linearly dependent* if some finite list of distinct vectors
$u_1,\ldots,u_n\in S$ has scalars, not all zero, such that
$$
\lambda_1u_1+\cdots+\lambda_nu_n=0.
$$

</Statement>

Dependence is exactly the failure of linear independence.

</Definition>

<Example slug="independence-parameter-test" of="linear-independence,linear-dependence" difficulty="routine">

### A parameter decides independence

Let
$$
u_1=\begin{pmatrix}1\\1\end{pmatrix},
\qquad
u_2=\begin{pmatrix}2\\\alpha\end{pmatrix}.
$$
The homogeneous relation
$$
\lambda_1u_1+\lambda_2u_2=0
$$
gives
$$
\lambda_1+2\lambda_2=0,
\qquad
\lambda_1+\alpha\lambda_2=0.
$$
If $\alpha=2$, the two equations are the same, so non-zero solutions exist and the set is dependent. If $\alpha\neq2$, subtraction gives $\lambda_2=0$, then $\lambda_1=0$, so the set is independent.

</Example>

## Testing independence by row reduction

When the vectors are placed as columns of a matrix, the definition becomes a
test on a homogeneous system.

<Theorem slug="homogeneous-independence-test" of="linear-independence,linear-dependence">

### The homogeneous-system test

<Statement>

Let $S=\{u_1,\ldots,u_n\}\subseteq\mathbb R^m$ and let
$$
A=[\,u_1\ \cdots\ u_n\,].
$$
Then $S$ is linearly independent if and only if the homogeneous system
$$
Ax=0
$$
has only the zero solution. Equivalently, after row reduction, every column
of $A$ contains a pivot. If a column has no pivot, the free variable in that
column produces a non-trivial dependence relation among the original
columns.

</Statement>

If $m<n$, there cannot be a pivot in every column, so any $n$ vectors in
$\mathbb R^m$ with $m<n$ are dependent.

When $S$ is dependent, the original vectors in the pivot columns form an
independent subset with the same span as $S$. This works because row
operations left-multiply by an invertible matrix, so they preserve every
linear relation among the columns. Each non-pivot column is therefore a
combination of the pivot columns, not necessarily only the earlier ones.

</Theorem>

<Example slug="independence-in-r3" of="homogeneous-independence-test" difficulty="routine">

### Two vectors in $\mathbb R^3$

Consider
$$
u_1=\begin{pmatrix}1\\-2\\3\end{pmatrix},
\qquad
u_2=\begin{pmatrix}-1\\2\\-4\end{pmatrix}.
$$
The equations in
$$
\lambda_1u_1+\lambda_2u_2=0
$$
include $\lambda_1-\lambda_2=0$ and $3\lambda_1-4\lambda_2=0$. Hence $\lambda_1=\lambda_2$ and then $\lambda_1=0$, so $\lambda_2=0$. The two vectors are linearly independent.

</Example>

<Example slug="dependent-set-independent-subset" of="homogeneous-independence-test,span" difficulty="routine">

### Removing a redundant vector

Let
$$
S=\left\{
\begin{pmatrix}1\\2\end{pmatrix},
\begin{pmatrix}1\\3\end{pmatrix},
\begin{pmatrix}1\\4\end{pmatrix}
\right\}.
$$
The third vector is twice the second minus the first, so it adds no new
direction. The first two vectors are independent because neither is a
scalar multiple of the other. Therefore
$$
\left\{
\begin{pmatrix}1\\2\end{pmatrix},
\begin{pmatrix}1\\3\end{pmatrix}
\right\}
$$
is independent and has the same span as $S$.

</Example>

## Independence is uniqueness

<Theorem slug="independence-unique-representation" of="linear-independence,span">

### Independence and uniqueness

<Statement>

Suppose
$$
v=\lambda_1u_1+\cdots+\lambda_nu_n.
$$
The coefficients $\lambda_1,\ldots,\lambda_n$ are unique if and only if $\{u_1,\ldots,u_n\}$ is linearly independent.

</Statement>

The [span](/algebra/vector-spaces/spans) gives existence of a representation; independence gives its uniqueness.

</Theorem>

<Proof of="independence-unique-representation">

If the coefficients in the displayed representation of $v$ are unique, suppose a non-zero relation
$$
c_1u_1+\cdots+c_nu_n=0
$$
exists. Then
$$
v=(\lambda_1+c_1)u_1+\cdots+(\lambda_n+c_n)u_n
$$
is another representation of $v$. Since some $c_j\neq0$, the two representations are different, a contradiction. Thus the set is linearly independent. Conversely, suppose
$$
v=\lambda_1u_1+\cdots+\lambda_nu_n
=\alpha_1u_1+\cdots+\alpha_nu_n.
$$
Subtracting gives
$$
(\lambda_1-\alpha_1)u_1+\cdots+(\lambda_n-\alpha_n)u_n=0.
$$
Independence forces $\lambda_j-\alpha_j=0$ for every $j$, so the two representations are the same.

</Proof>

<Example slug="dependent-representation" of="independence-unique-representation" difficulty="routine">

### Dependence gives non-unique coefficients

The set
$$
S=\left\{
\begin{pmatrix}1\\2\end{pmatrix},
\begin{pmatrix}1\\3\end{pmatrix},
\begin{pmatrix}1\\4\end{pmatrix}
\right\}
$$
is dependent. For example,
$$
\begin{pmatrix}1\\4\end{pmatrix}
=-\begin{pmatrix}1\\2\end{pmatrix}
+2\begin{pmatrix}1\\3\end{pmatrix}
=-2\begin{pmatrix}1\\2\end{pmatrix}
+4\begin{pmatrix}1\\3\end{pmatrix}
-\begin{pmatrix}1\\4\end{pmatrix}.
$$
The relation $(1,2)^T-2(1,3)^T+(1,4)^T=0$ explains the two
representations: adding a multiple of it changes the coefficients without
changing the vector.

</Example>

## Locating the redundant direction

Dependence can also be read as one vector lying in the span of the others.
The polynomial example below is over $\mathbb R$, so $P_1$ denotes
$P_1(\mathbb R)$.

<Theorem slug="independence-span-criterion" of="linear-independence,span">

### Independence and the span of the other vectors

<Statement>

A finite set $S$ is linearly independent if and only if no vector in $S$ belongs to the span of the other vectors.

</Statement>

If $u_j$ is a combination of the other vectors, moving it to one side gives a non-trivial relation equal to zero. Conversely, in a non-trivial relation, choose a vector with a non-zero coefficient and solve for it in terms of the others.

</Theorem>

<Example slug="polynomial-dependence" of="independence-span-criterion" difficulty="routine">

### Dependence in $P_1$

The set
$$
\{x,\ 1+x,\ 1-x\}
$$
is dependent: equating coefficients in
$$
\lambda_1x+\lambda_2(1+x)+\lambda_3(1-x)=0
$$
gives the non-trivial choice $\lambda_1=-2$, $\lambda_2=1$, $\lambda_3=-1$. The subset $\{x,1+x\}$ is independent, since the constant coefficient forces the coefficient of $1+x$ to be zero and then the coefficient of $x$ forces the other coefficient to be zero.

</Example>

## Extending an independent set

<Theorem slug="span-adjoining-criterion" of="span,linear-independence">

### Adding a vector to a span

<Statement>

For a finite set $S$ and a vector $v$,
$$
\operatorname{span}(S\cup\{v\})=\operatorname{span}(S)
$$
if and only if
$$
v\in\operatorname{span}(S).
$$

</Statement>

Since $S\subseteq S\cup\{v\}$, we always have
$\operatorname{span}(S)\subseteq\operatorname{span}(S\cup\{v\})$. If
$v\in\operatorname{span}(S)$, every combination using $v$ can be rewritten
using only vectors in $S$, so the reverse inclusion also holds. Conversely,
if the spans are equal, then $v$ belongs to $\operatorname{span}(S\cup\{v\})$
and hence to $\operatorname{span}(S)$.

</Theorem>

Two consequences follow. Removing any vector from an independent set leaves an independent set with a smaller span. From a dependent set, some vector can be removed without changing the span.

<Corollary slug="independent-adjoining" of="span-adjoining-criterion,linear-independence">

### Adjoining a vector outside the span

<Statement>

If $S$ is linearly independent and $v\notin\operatorname{span}(S)$, then $S\cup\{v\}$ is linearly independent.

</Statement>

</Corollary>

<Proof of="independent-adjoining">

Write $S=\{u_1,\ldots,u_n\}$. Suppose
$$
\lambda_1u_1+\cdots+\lambda_nu_n+\mu v=0.
$$
If $\mu\neq0$, then $v$ is a linear combination of the vectors in $S$, contradicting $v\notin\operatorname{span}(S)$. Hence $\mu=0$ and the independence of $S$ forces $\lambda_1=\cdots=\lambda_n=0$. Therefore $S\cup\{v\}$ is linearly independent.

</Proof>

This result is the step used to [extend an independent set to a basis](/algebra/vector-spaces/coordinates-and-bases).

[Basis and dimension](/algebra/vector-spaces/basis-and-dimension) combines spanning with independence and counts the vectors required.
